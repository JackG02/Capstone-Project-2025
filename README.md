# 🎓 Capstone Project 2025 – Minor Pathway Recommendation System  

This project was developed as part of my **Informatics Capstone at Indiana University**. It helps students discover minors and academic pathways based on their preferences, academic history, and advisor recommendations.  

## Features  
- **Student Portal** – allows students to browse, save, and request minors  
- **Advisor Dashboard** – tracks trends in minor selections and approval requests  
- **Role-Based Authentication** – Google OAuth login for secure access  
- **Data Visualization** – advisor insights with charts and trends  

## Tech Stack  
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP, MySQL  
- **Authentication:** Google OAuth  
- **Data Visualization:** Chart.js

## Security Notice  
Google OAuth credentials were removed for security reasons. This repo only contains the public-facing code and database structure.  

## How to Run (Locally)  
1. Clone the repo  
2. Set up a local PHP server (`php -S localhost:8000`)  
3. Import the included database schema into MySQL  
4. Configure your own Google OAuth credentials in `google-oauth.php`
